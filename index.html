03 / Estudio interactivo de variables

Clasifica: ¿categoría, conteo o medida?

La palabra “distributiva” no es la clasificación usada aquí: distinguimos variables cualitativas y cuantitativas; estas últimas pueden ser discretas o continuas.

Regla de oro

Primero pregunta qué tipo de dato tienes.

Si describe una categoría, es cualitativa. Si responde “¿cuántos?” o “¿cuánto mide?”, es cuantitativa.

CONTAR → DISCRETAValores separados y enteros.X ∈ {0, 1, 2, 3, …}
MEDIR → CONTINUAPuede aceptar decimales dentro de un intervalo.X ∈ [a, b]
CLASIFICAR → CUALITATIVANominal si no hay orden; ordinal si sí lo hay.X ∈ {categorías}
